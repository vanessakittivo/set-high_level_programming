# Python - Almost a Circle

## 📖 Description

This project is part of the **Higher Level Programming** curriculum.

The objective is to review and apply everything learned about Python, including:

- Classes and Objects
- Inheritance
- Encapsulation
- Serialization and Deserialization
- JSON
- CSV
- File handling
- Unit testing
- `*args` and `**kwargs`

The project implements a simple geometry library containing `Rectangle` and `Square` classes built on a common `Base` class.

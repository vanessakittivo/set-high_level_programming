# Python - Test-driven development

This project contains Python functions and tests developed using test-driven development.

## Tasks

### 0. Integers Addition
A function that adds two integers or floats after validating and converting the inputs.

### 1. Divide a Matrix
A function that divides all elements of a matrix by a given number.

### 2. Say My Name
A function that prints a person's first and last name.

### 3. Print Square
A function that prints a square using the `#` character.

### 4. Text Indentation
A function that prints text with two new lines after each `.`, `?`, and `:` character.

### 5. Max Integer - Unittest
Unit tests for a function that finds the maximum integer in a list.

### 6. Matrix Multiplication
A function that multiplies two matrices after validating their contents and dimensions.

### 7. Lazy Matrix Multiplication
A function that multiplies two matrices using NumPy.

## Testing

Doctests can be executed with:

```bash
python3 -m doctest -v tests/<test_file>.txt

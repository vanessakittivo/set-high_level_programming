# Python - Network #0

## Description
This project covers Bash scripting with `curl` for HTTP requests and a Python technical interview task for finding a peak in an unsorted list.

## Tasks

| Task | File | Description |
|------|------|-------------|
| 0 | `0-body_size.sh` | Get response body size in bytes |
| 1 | `1-body.sh` | GET request, display 200 response |
| 2 | `2-delete.sh` | DELETE request |
| 3 | `3-methods.sh` | Show allowed HTTP methods |
| 4 | `4-header.sh` | GET with custom header |
| 5 | `5-post_params.sh` | POST with parameters |
| 6 | `6-peak.py` | Find peak in unsorted list (O(log n)) |
| 7 | `101-post_json.sh` | POST JSON from file |
| 8 | `100-status_code.sh` | Display only status code |
| 9 | `102-catch_me.sh` | Request that returns "You got me!" |
